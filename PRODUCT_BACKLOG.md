# Product Backlog

## Guided Learning

- On a player's first launch of each game, ask whether they already know the rules.
- "Show me" opens the relevant How to Play content; "I know it" begins the game.
- Remember the choice per game and keep How to Play available from the existing help control.

## Customization Previews

- Make board, tile, and card-theme selectors tappable previews before equip/purchase.
- Preview the selected theme in a representative live mini-board, not only a color swatch.
- Keep preview interactions local until the user confirms Equip.
